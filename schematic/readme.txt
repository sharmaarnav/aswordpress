A technical journal theme for long-form engineering notes.

== Description ==

Schematic sets a technical blog as a journal: a lead note, a numbered index, series that read in order, and a heading outline beside the article.

* Paper and oxide color system, plus a night theme
* Fraunces, Source Serif 4, and IBM Plex Mono (SIL Open Font License)
* Series taxonomy for multi-part notes
* Reading time, word count, and article metadata
* Note, warning, pull-quote, and definition patterns

Assign the Primary menu, write the site tagline, and add a manual excerpt when a note needs a deck.

== Installation ==

1. Upload the `schematic` folder to `/wp-content/themes/`.
2. Activate the theme under Appearance → Themes.
3. Optional: import sample notes with `wp eval-file demo/seed.php` from the project repository.
